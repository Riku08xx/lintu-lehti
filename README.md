# Lintu & Lehti — 鳥と葉っぱのカフェ

架空の北欧風カフェ「Lintu & Lehti（リントゥ・ア・レヘティ＝鳥と葉っぱ）」の公式サイト、という設定のポートフォリオ作品です。
**このサイトは架空のカフェです。** 実在の店舗・場所・人物とは関係ありません。

## 見どころ

- **扉を開けて入店**：木の扉を押すと扉が開き、看板インコの Taivas（青）と Aurinko（黄）が飛び出して、店内の木にとまります。
- **木の目次**：大きな木の枝にぶら下がった札が、各ページへの入口です。
- **インコと一緒に飛ぶページ移動**：奥・中・手前の3層の背景を動かし、葉っぱの中を抜けて次の場所へ飛んでいくように切り替わります。
- **インコを押すと飛び立つ**：どのページでも、インコを押すとパッと飛び立ち、少しして戻ってきます。
- **ドリンク調合**：メニューでドリンクを選ぶと、カップに注がれて小鳥のラテアートが描かれます（ソーダは泡と羽根ミント）。

## つくり

- HTML / CSS / JavaScript のみ（ライブラリ・ビルドなし）
- イラストはすべてコードで描いた SVG（外部の画像素材なし）
- 外部への通信なし（予約フォームも送信されません）
- スマホ対応、キーボード操作対応、「視差効果を減らす」設定に対応
